# AdventureCamp
NAMA  : SAHRIL GUNAWAN
NIM   : C2583207047
NAMA PROJECT : AdventureCamp
Descripsi : Adventure Camp adalah aplikasi berbasis bahasa C untuk menyewakan peralatan camping. Program menyediakan daftar harga, perhitungan biaya dan diskon otomatis, struk pembayaran, serta riwayat maksimal 10 transaksi. Program menggunakan fungsi, array, percabangan, perulangan, dan validasi input.
